Approved delivery under Fleet Coherencev1 `entry_3259`. The collision page is `../collision.md`; Axiom integrates it. This is a draft asset, not a source/main publication.

From the extracted `g8_why` directory:

```sh
python collision/reader.py .
```

The reader requires Python, NumPy and SciPy. It verifies every `collision/` member and `collision.md`, replays the saved Eq7 rate nodes and actual pinned normalized readout, checks the exact rational monotonicity certificate, and consumes the finite-local pilot joint measure. GPAW and ASE imports are refused. Other mechanism pages are outside this capsule's namespace.

No Native, harmonic, grid, optimization or nuclear-state production is launched. The grid dependency assessment uses existing source and controls only. Physical tail, converged anharmonic ratios and n18 are closed omissions, not pending calculations or zero-valued physical predictions.

`manifest.json` preserves ORIGINAL and EXPORTED byte counts/SHA256 with explicit private-path transformations. Complete findings and all numeric data survive export; `.npz` arrays are byte-exact. Producer sources are retained for provenance; their private path defaults are redacted, not claimed to reproduce private-host launching. Full orbitals/eigenvector matrix, PDFs, GPAW user headers and provider/session/launch payloads are not distributed. Missing original private path/header bytes cannot be reconstructed.

The archive SHA256 binds the manifest externally; a manifest is not a signature. A separate portability proof binds the actual sealed archive and includes a meaningful wrong-reported-value refusal after repairing only EXPORTED hashes in a negative copy. No original evidence is changed by that exercise.
