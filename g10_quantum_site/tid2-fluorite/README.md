# G10 — Static wells in constrained cubic fluorite TiD₂

This calculation varies the cubic lattice size at zero external pressure while holding the exact fluorite site fractions. The admitted lattice parameter is **4.423103 Å** and the initial nearest-neighbour D–D separation is **2.211552 Å**. The input seed came from Er et al. ([arXiv:0910.1003v1](https://arxiv.org/abs/0910.1003v1), Table 1), a calculation for TiH₂. This is a fingerprint of the chosen constrained phase; it does not establish the foil's TiD stoichiometry, phase, occupancy, or stability against a tetragonal distortion. The static electronic calculation uses H setups with D masses recorded in the geometry.

- `native/relax/reference.json` contains the final primitive solution, all-index geometry of the 24-atom sampling cell, nearest-pair definition, and hashes of the completed relaxation trials. The base sampling repeat uses all four-by-four-by-four k-points with only time reversal, rather than the primitive reference's point-group reduction.
- `native/cuts.json` indexes the three signed directional cuts against the common zero. Original D8 moves on fixed Cartesian [100], [110] or [111] axes. Both signs are independently computed; the two signs of [111] face inequivalent local Ti environments. Keep the full signed data, not only a fitted harmonic width. `native/<case>/point.json` gives each native energy and all Cartesian forces in original atom order.
- `native/pair.json` reports D8 and D19 moving equal distances toward one another along their original [100] separation while all other ions and the cell remain fixed. Matched 0, A, B and AB controls give the connected energy E(AB)−E(A)−E(B)+E(0). The mixed vector force response at fixed indices is not the derivative of the pair path; a separate path force is supplied. Use the reported nearest Ti distances to identify strong compression. No separate short-distance PAW validation is claimed.
- `native/setting.json` compares the energy rise and full force response for the same zero and −0.48 Å [111] point at two k meshes. This bounds neither the full curve nor any close pair; read the actual differences and target status rather than treating refinement as a pass by default.

All energies are force-consistent electronic free energies. These frozen-ion surfaces do not give reaction rates, transient screening during arrival, or a thermal distribution. `SHA256SUMS` binds the saved records. Source identity uses archive member names plus byte counts and SHA-256; machine paths are not part of these JSON records.

After `sha256sum --check SHA256SUMS`, verify the readouts against their native records with `python replay/replay_tid2.py native` (ASE, NumPy and SciPy; no GPAW, original PDF or PAW data needed). Recomputed scientific floats allow absolute roundoff up to 1e-9; source hashes, keys, index values and flags must match exactly. Source binaries and raw solver logs are referenced by SHA-256, not redistributed.
