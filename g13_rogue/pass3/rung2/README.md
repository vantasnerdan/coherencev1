## Next scientific decision — proposal only

Unresolved short waves would need a **whole-foil** position/direction/frequency-resolved wave-action or energy-density transport model, not an isolated patch or another ad hoc long-mode kick. Its sources would share the existing parent count stream and an explicitly partitioned host-recoil spectrum; propagation would use anisotropic branch group velocities, grain transmission/scattering, free-face reflection and a stated decay law, with the resolved long-wave strain as a common background. Such a phase-averaged model could address coarse energy concentration and transport tails, **not** by itself signed coherent rogue crests, the current A/C predicates or atom-local D energies.
