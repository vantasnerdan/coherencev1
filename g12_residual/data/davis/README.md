# UC Davis: public 48-point covariate intake

`uc_davis.csv` reproduces the exact adopted [Fig. 2 digitization](https://github.com/vantasnerdan/coherencev1/blob/bf114e0874f2a01dc62505e7c7520cadf46fd20f/g4_beam/forward/errbars.csv): 48 analysis points plus four normalization rows. Match `(target, E_cm_keV)`; each target has its **own** 6.50-keV reference (`reference_group`). The four normalized ones are anchors, not independent observations. `sigma_minus/plus` are the adopted linear half-width, not calibrated independent errors; `adopted_sigma_ln_R` retains the existing transform/floor. The underlying covariance and the exact proton/neutron combination at overlapping energies are not supplied. The [paper](https://doi.org/10.1038/s41467-026-74421-1) states below 3 keV proton only; higher-energy evidence classes reflect the stated acquisition regimes, not a channel-resolved ledger.

| Field family | Source and scope |
|---|---|
| `cup_IV_*` | Supplementary Table 1 exact calibration values through 3.0 keV CM, above that Supplementary Fig. 3 at actual plotted markers; voltage corresponds to nominal D⁺ lab energy, twice CM. From the published graph raster (140 dpi), y=747.5 px at 0 µA and y=150.5 px at 300 µA; centers read from the black squares, rounded to 1 µA, approximately ±1 µA digitization. The bars represent about ±5 µA repeat spread, not the uncertainty of each fusion run. The seven exact Table 1 currents agree with the plotted marker readings. Fig. S3 shows external focusing; do not assume this is true incident charge or infer point flux/dose from it. |
| Counts, time, dose | `proton_signal_background_ratio_author` is from SI Table 1; it is partly constructed from yield and should not be a regressor. 12–24 h is a stated range for the ≤2-keV block, not an exact run time; >350 h is background exposure, and the ~1-h statement is a neutron detectability example, not an assigned point exposure. No actual current, dose, cumulative dose, live-time or run IDs are published at the 48-point resolution. |
| Range and beam context | SRIM implantation depth endpoints 4.4 and 67.5 nm are source **simulation** values, not measured ion ranges; the paper does not tabulate intermediate values. The 200-nm depth elsewhere is a representative *mixing* depth, not the point range; the repository's separate range calculation is not imported here. 1 cm² spot, 150 µA current, 85/15 ion mixture, ~1.1×10¹⁵ D cm⁻² s⁻¹ flux and ~5% retarding-analyzer spread describe apparatus/typical conditions, not 48 measured values. No numerical spread definition or retarding curve was published. |
| Foil, loading and host | Methods Materials, Cathode preparation, Vacuum, Electrochemical cell, Structural analysis and SI Fig. 2. Anneal 400°C is *preparation*, not target temperature during a point. Nominal D/metal terminal solubility and metal atom densities are context, not actual loading or electron density. The cited 1.6–1.9 D/Ti δ-phase field at room temperature is an interpretation of ex-situ XRD, not a per-point assay. Beam-only does not mean D-free. The Ti/Pd face coatings refer to opposite sides. Missing numeric transport/host properties stay blank; qualitative comparisons use the paper's wording. |
| Screening | Authors' bulk fits over 2.5–6.5 keV (main Fig. 2; ±0.2 keV) and surface/crossover values (SI Table 2). These are source outcomes **derived from these same yields**, not independent covariates. |

**Main omissions:** Run/point exposure, charge and thermal/load histories are absent; intermediate measured implantation depths/energy spectra and pointwise illuminated areas are absent; the normalization covariance and channel-specific ledger are absent. The [Zenodo record](https://zenodo.org/records/20435774) is embargoed until December 1, 2026 and no files from it were accessed. Scope is the published paper/SI and the existing digitization only.
