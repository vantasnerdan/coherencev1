# PdD full-zone size diagnostic — not an MD input

These are the exact 300/3,000 K, parent 16³ comparisons for the ordered, fixed-volume rocksalt reference. The archive includes the native force JSON and logs, raw and projected IFCs, Phonopy paths and all 24³ q-point spectra and eigenvectors for the seven comparisons. It is not the full temperature ladder or a convergence certificate.

- **The collective Γ anchor survives.** Original primitive stiffness changes by +43.208% at its 0.07367958 eV/D internal excitation anchor. Clamped-Pd, raw D→D sublattice sums give +43.322% (16 atoms) and +43.312% (64 atoms). The changes in the on-site and summed other-D terms nearly compensate at Γ. Neither this percentage nor the compensation is a local or low-excitation result.
- **The full-zone thermal size screen fails.** The maximum hot-minus-cold 6×6 reciprocal stiffness difference is 0.314158 eV/Å² versus a maximum 64-atom response of 0.323812 eV/Å²; 13,618 of 13,824 q points exceed the registered pointwise tolerance. The largest difference in sorted heating-induced spectral shifts is 1.14606 THz; sorting is not branch tracking.
- **The band profile passes only with matched tighter force convergence.** At the loose setting the 80/56-band operator difference is 0.00212954 eV/Å². It falls to 0.00000974338 eV/Å² in the tighter pair, below 0.0005, with occupations below 10⁻¹⁰. This qualifies the 448-band 128-atom trial, not the larger-cell response. Its first local cold D launch stopped during initialization; no 128-atom force or 64→128 result is asserted.

Keep the thermal correction out of MD until both the larger-cell and electronic-mesh tests pass. The three largest omissions are longer-range IFC convergence, fractional loading and defects, and non-adiabatic or spatially inhomogeneous electronic dynamics. The harmonic difference must not double-count the cold force field.

Run `sha256sum -c SHA256SUMS` in the extracted directory. With the observed runtime from `requirements.txt`, run `python src/replay_size_anchors.py .`. This independently assembles the stored force columns through standard Phonopy, checks both saved IFCs per case, and replays the Γ, size and band comparisons. The per-case source snapshots under `sources/` are the exact producers, not a common guessed revision. PAW identities are in the native metadata. To regenerate a spectrum, use `src/phonon_dispersion.py --help` and the matching native directory, source snapshot, and `records/folded-response.json`. Use `--compact-bands` for `band-control`/`tight-band-control` and `--tight-forces` for both `tight` lanes. No GPAW SCF run is needed for the diagnostic replay.
